# ملفات الأوامر

يحتوي هذا المجلد على أوامر مستقلة تعمل داخل قروبات Messenger:

| الملف | الأمر | الوظيفة |
| --- | --- | --- |
| `marriage.js` | `.زواج` / `.marriage` | تقرير زواج مرح بين المرسل وعضو تم الرد على رسالته، أو عضو عشوائي. |
| `divorce.js` | `.طلاق` / `.divorce` | تقرير طلاق مرح بين عضوين. |
| `love.js` | `.حب` / `.love` | نسبة توافق عشوائية مع تعليق مرح. |
| `khotba.js` | `.خطبة` / `.khotba` | تقرير خطبة مرح بين عضوين. |
| `kizb.js` | `.كذب` / `.kizb` | نسبة كذب عشوائية وتعليق مرح لعضو. |
| `registry.js` | — | يربط أسماء الأوامر بملفاتها، ويحمّل الملف المطلوب عند استخدامه فقط. |

## واجهة الأمر

يصدّر كل ملف أمر `name` و`execute(context)`. يقوم `bot.js` بتمرير `api` و`event` و`args` و`data` و`senderID` و`threadID` و`messageID` و`sendMessage`. لا تنشئ ملفات الأوامر جلسة Messenger مستقلة.

تستخدم الأوامر صورة العضو التي توفرها بيانات `getUserInfo` عند وجودها. إنشاء بطاقة الصورة يحتاج `canvas`؛ وعند غياب المكتبة أو الصورة، يستخدم الأمر رسالته النصية الاحتياطية. لا تضع رموز وصول أو أسرار داخل روابط الصور أو ملفات الأوامر.
